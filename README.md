# 📚 Personal Study Tracker

A Personal Study Tracker built using Python and Streamlit. This application helps users manage their study subjects and record daily study sessions.

---
## 🚀 Live Demo

👉 [Open Personal Study Tracker](https://personal-study-tracker-ffduqzduahfnqqhybtpzzf.streamlit.app/)


## 🚀 Features

- User Registration
- User Login
- Add Subject
- View Subjects
- Update Subject
- Delete Subject
- Add Study Record
- View Study Records
- Update Study Record
- Delete Study Record
- Data stored using JSON files
- Simple Streamlit web interface

---

## 🛠 Technologies Used

- Python
- Streamlit
- JSON
- Object-Oriented Programming (OOP)

## ▶️ Installation

Clone the repository

```bash
git clone https://github.com/yourusername/Personal-Study-Tracker.git
```

Move into the project

```bash
cd Personal-Study-Tracker
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```
